# Съёмка пилотного района — Луначарка (на карте «Мікрорайон Лісовий»)

Задача: пройти **все точки из `points.json`** и сохранить по одному снимку на точку. Ничего не разбирать и не описывать — разбор потом делает другая модель. Папка работы: `/home/claude/walk/pilot`.

- `A001…A100` — вид сверху (спутник, зум 19), сетка над всем районом.
- `P0001…P0629` — панорамы улиц (Google Просмотр улиц), уже с направлением взгляда.

## Команды

```
cd /home/claude/walk/pilot
python3 next.py 8                       # следующие 8 несделанных точек и их адреса
python3 shot.py ID ПУТЬ ok "АДРЕС_ВКЛАДКИ"   # записать снимок (ПУТЬ — из «Image source: …» после скриншота)
python3 shot.py ID - no_pano            # панорамы нет / Google показал «нет изображений»
python3 shot.py ID - black              # кадр чёрный или скриншот дважды не снялся
python3 sync.py                         # перенос новых снимков на ПК (см. ниже)
```

`АДРЕС_ВКЛАДКИ` — адрес этой вкладки из блока «Tab Context» после скриншота (там настоящее место камеры). Для вида сверху его можно не передавать.

## Браузер

Claude in Chrome. В начале: `tabs_context_mcp` (createIfEmpty: true). Нужны **две вкладки** — назовём их T1 и T2 (вторую создай `tabs_create_mcp`, если её нет). `browser_batch` работает только с одной вкладкой за раз.

## Вид сверху (A…) — одна вкладка, один `browser_batch` на точку

1. `navigate` на адрес точки
2. `wait` 5 с
3. `left_click` по (700, 400) — закрывает панель поиска слева (проверено, место карты пустое)
4. `wait` 1 с
5. `screenshot` с `save_to_disk: true`, `scale: 1`

Потом `shot.py ID ПУТЬ ok`.

## Панорамы (P…) — «конвейер» из двух вкладок

Свежезагруженная панорама в той вкладке, что открыта последней, **не снимается** (скриншот висит 30 с). Снимается вкладка, после которой уже открыли другую. Поэтому чередуй:

```
navigate T1 → P(n)
navigate T2 → P(n+1)
screenshot T1 (save_to_disk, scale 0.8) → shot.py P(n) …
navigate T1 → P(n+2)
screenshot T2 → shot.py P(n+1) …
navigate T2 → P(n+3)
screenshot T1 → …   и так далее
```

Если скриншот всё же завис — открой следующую точку в другой вкладке и попробуй снова один раз; не вышло — `black`.

## Когда что ставить

- `ok` — видна улица (даже если это поле или стройка — так и надо, это 2015 год).
- `no_pano` — Google пишет, что изображений нет, или открылся не Просмотр улиц, а карта.
- `black` — чёрный/серый кадр после повтора.
- **Капча или «необычный трафик» — сразу СТОП.** Не проходить, ничего не нажимать. `shot.py ID - captcha`, перенести снимки на ПК и написать пользователю.

`E:\AI_Workspace\01_PROJECTS\Active\Games\Game_01_UNTITLED\01_refs\survey\lunacharka\shots`.
