# Mapillary для игры (знаки, столбы, фонари, люки)

Скрипт скачивает с Mapillary только точки: тип объекта и координаты. Фотографии не качает.
Ключ вводишь сам в окне. Он нигде не сохраняется и в чат его присылать не нужно.

## Что сделать один раз

1. Зайди на https://www.mapillary.com и войди в аккаунт (регистрация бесплатная).
2. Открой раздел для разработчиков: https://www.mapillary.com/dashboard/developers
3. Приложение уже создано (`city-game-prototype`), этот шаг пропусти.
   Если форма просит адрес, впиши `https://example.com`. Остальное оставь как есть.
4. В таблице приложений в колонке **Access Token** нажми зелёную ссылку «View» и скопируй ключ. Он начинается с `MLY|`.

## Запуск

1. Двойной клик по `run_mapillary.bat` (лежит в этой же папке).
2. В чёрном окне вставь ключ правой кнопкой мыши и нажми Enter. Символы не видны, это нормально.
3. Скрипт сначала сделает пробу на центре города и покажет, сколько нашёл. Если нашёл, ответь `д`.
4. Скачивание идёт от 10 минут до часа. Можно закрыть окно или нажать Ctrl+C, при новом запуске докачает с того же места.
5. Когда напишет «Готово», скажи Claude: «Mapillary скачан».

## Что появится

Папка `data\city\`:
- `mapillary_cherkasy.json` — все объекты (тип, широта, долгота);
- `summary.txt` — сводка: сколько каких знаков, столбов, фонарей;
- остальное — служебные файлы для докачки.

Папка `data\_probe\` — результат пробы, её можно не трогать.

## Если что-то пошло не так

- «Не нашёл Python» — напиши Claude, подскажет другой способ.
- «Mapillary не принял ключ» — проверь, что скопировал именно Access Token целиком, вместе с `MLY|`.
- После скачивания ключ можно сменить или удалить на той же странице для разработчиков.
