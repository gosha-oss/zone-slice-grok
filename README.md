# UNTITLED — игра про послевоенные Черкассы (серый прототип)

Названия пока нет. Движок — Godot 4.7. Сейчас это техническая база: весь город серыми коробками, герой от первого лица, игровые часы, день и ночь.

## Как запустить
1. Открой Godot 4.7 → «Импорт» → выбери файл `project.godot` в этой папке.
2. Первый раз Godot минуту готовит файлы. Потом нажми **F5** (или кнопку ▶ справа сверху).

## Управление
| Что | Клавиатура | Геймпад |
|---|---|---|
| Идти | W A S D | левый стик |
| Смотреть | мышь | правый стик |
| Бег | Shift | нажать левый стик |
| Присесть | Ctrl или C | B / кружок |
| Прыжок | Пробел | A / крестик |
| Карта | M | Share / Back |
| Отпустить мышь | Esc | Options / Start |

Тестовые кнопки (уберём позже): **V** — полёт, **T** — плюс один час, **[ ]** — скорость времени, **F5 / F6 / F7** в игре — дальность прорисовки (низко / средне / ультра), **F3** — цифры. На карте правая кнопка мыши переносит героя в точку.

## Что внутри
- `city/` — готовые данные города: рельеф, дома, дороги, вода, карта.
- `world/` — подгрузка города квадратами 256×256 м, день и ночь, блокпосты.
- `player/` — герой. `ui/` — экран и карта. `autoload/` — часы, кнопки, данные города.
- `tools/build_city.py` — пересборка города из исходной карты (исходники лежат на ПК в `03_source_assets/map`).
- `tools/auto_test.gd` — автопроверка: `godot --path . -- --autotest=ПАПКА`.
