# BuildHub

Локальный прототип BuildHub: стартовый экран, пространство проекта и рабочие демо-данные.
Это не продакшен: нет аккаунта, сервера, совместной работы и каталога сообщества.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://127.0.0.1:5173

Сборка:

```bash
npm run build
npm run preview
```

Проверка типов входит в `npm run build`.

## Что есть сейчас

- Три темы: Abyss, Light, Graphite. Тема меняет интерфейс и сцену.
- Демонстрационный режим подписан. Данные лежат в `localStorage` этого браузера и переживают перезагрузку.
- Стартовый проект «Архив Люмен» и проекты, которые вы создаёте.
- Форма проекта: название, краткое описание, категория, цель, тип, видимость, начальный этап. После создания открывается его пространство.
- Задачи: статус, приоритет, исполнитель из локального списка, срок. Прогресс — `завершённые / все задачи × 100`. Если задач нет, будет 0%, не NaN.
- Новый этап появляется в той же сцене. Готовый этап выглядит закрытым. Задача «в работе» визуально выделена.
- Участники — заранее подготовленный список. Это не приглашения и не совместная работа.
- Камера: мышь и тач, клавиши, кнопка «Общий вид». Есть упрощение графики и `prefers-reduced-motion`.
- Без WebGL остаётся плоская схема тех же данных: `http://127.0.0.1:5173/?webgl=0`.

## Чего нет

Панели обзора, дорожной карты, файлов, активности и ИИ, каталог сообщества и Supabase — следующие этапы. «Исследовать проекты» открывает заготовку каталога, а не социальную сеть.
