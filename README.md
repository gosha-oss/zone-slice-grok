# BuildHub

Локальный прототип BuildHub: стартовый экран, пространство проекта и рабочие демо-данные.
Это не продакшен: нет аккаунта, сервера и совместной работы.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://127.0.0.1:5173

Сборка:

```bash
npm run build
npm run preview
```

Проверка типов входит в `npm run build`.

## Что есть сейчас

- Три темы: Abyss, Light, Graphite. Тема меняет интерфейс и сцену.
- Демонстрационный режим подписан. Данные лежат в `localStorage` этого браузера и переживают перезагрузку.
- Стартовый проект «Архив Люмен» и проекты, которые вы создаёте.
- Форма проекта: название, краткое описание, категория, цель, тип, видимость, начальный этап. После создания открывается его пространство. Публичный проект появляется в каталоге этого браузера, приватный туда не попадает.
- Задачи: статус, приоритет, исполнитель из локального списка, срок. Прогресс — `завершённые / все задачи × 100`. Если задач нет, будет 0%, не NaN.
- Новый этап появляется в той же сцене. Готовый этап выглядит закрытым. Задача «в работе» визуально выделена.
- Панели проекта поверх той же сцены: обзор, задачи, дорожная карта с зависимостями, демо-файлы, команда, события и помощник.
- Помощник отвечает заранее написанным текстом по данным проекта. Это не подключённая модель и не поток токенов.
- Приглашение и смена доступа помечены как недоступные: сервера нет, приглашение не отправляется.
- «Войти в пространство» открывает полёт по Digital Abyss: WASD, мышь, сброс вида, скорость и чувствительность. Внутри открытого проекта камера по-прежнему облетает его объекты.
- Камера проекта: мышь и тач, клавиши, кнопка «Общий вид». Есть упрощение графики и `prefers-reduced-motion`.
- «Исследовать проекты» показывает только открытые проекты этого браузера. Поиск, фильтры, интерес, локальный запрос на участие и локальный запрос участников. Закрытый «Архив Люмен» в каталог не попадает.
- Без WebGL остаётся плоская схема тех же данных: `http://127.0.0.1:5173/?webgl=0`.

## Чего нет

Запросы каталога никому не доставляются. Загрузка файлов в хранилище недоступна. Приглашения в команду не отправляются. Supabase нет. Это не продакшен.
