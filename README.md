# BuildHub

Первый срез BuildHub: стартовый экран и одно пространство проекта в эстетике Digital Abyss.
Это локальный прототип. Он не готов к продакшену: нет аккаунта, базы, совместной работы и каталога сообщества.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://127.0.0.1:5173

Сборка:

```bash
npm run build
npm run preview
```

Проверка типов входит в `npm run build`. Отдельно: `npx tsc -b --pretty false`.

## Что есть в этом срезе

- Три темы: Abyss, Light, Graphite. Тема меняет интерфейс и сцену.
- Один тестовый проект «Архив Люмен» в локальных данных.
- Прогресс считается как `завершённые / все задачи × 100`. Если задач нет, будет 0%, не NaN.
- Сцена и панель читают одни и те же данные.
- Камера: мышь и тач, клавиши на компьютере, кнопка «Общий вид».
- Упрощение графики и учёт `prefers-reduced-motion`.
- Если WebGL нет, остаётся плоская схема тех же объектов. Тот же вид можно открыть как `http://127.0.0.1:5173/?webgl=0`.

Демонстрационный режим подписан в интерфейсе. Входа, живой модели и мультиплеера здесь нет.

## Чего нет

Создание проекта, правки задач, панели рабочего пространства, каталог сообщества и Supabase — следующие этапы. «Исследовать проекты» открывает заготовку каталога, а не социальную сеть.
